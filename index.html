Dashboard Petunjuk
Petunjuk Penggunaan
  1. Gunakan scroll mouse untuk memperbesar dan memperkecil peta.
  2. Klik dan tahan peta untuk menggeser tampilan.
  3. Klik polygon permukiman untuk menampilkan atribut pada panel informasi tetap.
  4. Gunakan tombol Area Data untuk kembali ke cakupan data.
  5. Gunakan tombol Lokasi Saya untuk menuju lokasi pengguna.
  6. Gunakan tombol Fullscreen jika ingin memperbesar area peta.
