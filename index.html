Dashboard Petunjuk
Petunjuk Penggunaan
  1. Gunakan scroll mouse untuk memperbesar dan memperkecil peta.
  2. Klik dan tahan peta untuk menggeser tampilan.
  3. Klik marker fasilitas umum untuk menampilkan atribut pada panel informasi.
  4. Gunakan tombol kategori untuk memfilter jenis fasilitas.
  5. Gunakan tombol Area Data untuk kembali ke cakupan data.
  6. Gunakan tombol Lokasi Saya untuk menuju lokasi pengguna.
  7. Klik Login Admin untuk masuk ke halaman pengelolaan data.
